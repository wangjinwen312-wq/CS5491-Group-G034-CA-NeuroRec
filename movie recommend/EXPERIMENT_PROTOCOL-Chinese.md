# 实验协议

这份说明列出小组作业统一采用的实验规则。所有模型共用这些规则，不根据测试结果临时修改。

## 1. 研究问题

在相同数据与评测条件下，将电影类型信息加入 NeuralCF，能否降低评分预测误差，并改善 Top-K 推荐？对于训练交互较少的用户和电影，效果是否不同？

主要比较为 NeuralCF 与 ContentAware。UserCF、ItemCF、MF 提供传统与可学习模型的参照。允许零提升或退化的结果；结论以真实实验为依据。

## 2. 数据与划分

- 使用官方 MovieLens 1M 全量数据，保留有效的 1–5 分显式评分。
- 按全局时间升序固定划分，目标比例为训练 80%、验证 10%、测试 10%。
- 相同时间戳的评分不跨分区，因此实际比例允许与目标略有偏差。
- 训练时间早于验证，验证早于测试。随机种子不重新划分数据。
- 原始用户/电影 ID 到连续索引的映射只提供标识，不使用留出评分估计参数。
- 电影名称和类型是静态内容信息，允许用于解析目录；电影类型向量只通过训练评分学习。
- 归一化、平均评分、相似度、交互数量、近邻和模型参数仅从训练集估计。

按全局时间划分会产生训练期未出现的新用户或电影。保留这些评分用于整体评分误差，记录其数量和统一回退策略。排名评价限定于训练出现过的用户和电影，并报告过滤与覆盖情况。两者回答的问题不同，不能将排名指标解释为全体新用户或新电影的效果。

## 3. 训练任务

MF、NeuralCF、ContentAware 均进行显式评分回归，采用评分误差训练。训练记录中 1–3 分的评分同样保留，不作为缺失数据删除。

没有为回归训练构造未交互“负样本”。排名时直接按模型预测评分降序排列。已观测低评分与未观测偏好是不同信息。

所有方法的评分预测统一限制在 [1,5]。排名按未截断的预测分数排序，以避免截断造成额外并列。冷启动统一采用下面的规则，均值只从训练集计算：

| 用户是否在训练中出现 | 电影是否在训练中出现 | 回退预测 |
|---|---|---|
| 是 | 否 | 该用户的训练平均评分 |
| 否 | 是 | 该电影的训练平均评分 |
| 否 | 否 | 训练集全局平均评分 |

验证集仅用于早停；测试集不参与训练、早停和参数选择。训练完成后不再使用训练集加验证集重新训练，所有保存的结果对应相同训练边界。

## 4. 评分预测评价

对全部当前留出评分计算：

\[
\mathrm{RMSE}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}(r_i-\hat r_i)^2},\qquad
\mathrm{MAE}=\frac{1}{N}\sum_{i=1}^{N}|r_i-\hat r_i|.
\]

RMSE 和 MAE 越低越好。不能只评价评分 ≥4 的记录。测试集中的训练未见 ID 必须采用预先固定的回退，不能直接使用随机、未训练 Embedding 预测。

## 5. Top-K 评价

### 5.1 喜欢与候选

- 真实评分 ≥4 的电影定义为该用户当前留出集的相关电影。
- 候选目录为训练集出现过的电影。
- 验证时排除训练集中该用户已评分的电影。
- 测试时排除训练和验证集中该用户已评分的电影。
- 测试目标电影必须留在候选中，不能把完整数据集的“所有已看电影”一并排除。
- 当前留出集相关电影要与候选目录取交集。
- 使用全候选排序，不采样评估负例。候选与排除规则对所有模型一致。
- 预测分数相同时采用固定的电影索引次序，避免不确定并列排序。

只有训练集出现过且当前有效相关集合非空的用户进入 Top-K 宏平均。训练未见用户、无有效相关电影用户单独计数，不能偷偷将其忽略而不说明。

### 5.2 指标

对于用户 u，推荐列表前 K 项为 L(u,K)，当前相关集合为 R(u)：

- Precision@K = |L(u,K) ∩ R(u)| / K。
- Recall@K = |L(u,K) ∩ R(u)| / |R(u)|。
- DCG@K 使用二元相关性，命中位置 j 的贡献为 1/log₂(j+1)，j 从 1 开始。
- IDCG@K 为 min(K, |R(u)|) 个相关电影排在最前时的 DCG。
- NDCG@K = DCG@K / IDCG@K。

先分别计算每个有效用户的指标，再对用户等权平均。正式报告 K=5、10、20。不以交互数量加权，不将用户级宏平均与交互级微平均混用。

未交互电影缺少真实偏好标签，本协议仅按留出正例进行离线检索评价。全候选评价的数值不能直接与“一个正例加若干采样负例”的文献结果横向比较。

## 6. 固定参数与重复实验

- 所有模型使用同一次固定划分、候选集合与评估实现。
- 为控制大学生课程作业的复杂度，参数预先固定，所有算法的参数搜索预算均为 0。
- 神经模型使用相同的 32 维 Embedding、学习率 0.003、训练批大小 8192，最多 12 轮；采用相同的验证早停规则，耐心值为 3 轮。
- UserCF、ItemCF 的近邻数和相似度收缩参数同样提前固定，并保存在配置中。不同算法不要求参数名相同或训练耗时相同。
- 不根据测试表现反复修改参数。固定参数不能保证每个算法都达到最优效果，这一局限在结果分析中说明。
- 使用五个训练随机种子：11、22、33、44、55。
- 五种算法每个种子都重新创建模型、拟合并评价，共 25 次真实执行；另外执行 5 次独立 GenreOff 训练，总计 30 次拟合。每次执行记录在 `execution_log.csv`，不把同一次拟合结果复制成多次执行。
- 神经模型固定种子控制初始化与训练样本顺序；记录早停规则和所选轮次。调试模式只用一个种子、最多两轮，不能替代正式五种子结果。
- UserCF、ItemCF 每个种子也独立执行。由于算法本身确定，固定数据下仍可以得到相同结果，标准差为 0 是正常情况，不能为产生非零标准差而扰动数据。
- 最终汇总报告均值、样本标准差（ddof=1）和有效重复数 n。一个种子的调试实验没有可估计的样本标准差。

## 7. Genre 消融

Genre on 与 Genre off 共享同一份模型实现。关闭类型后恢复 NeuralCF 的结构、初始化规则和训练设置。GenreOff 对每个种子都从头初始化并独立训练，使用与 NeuralCF 相同的样本顺序和早停规则，不加载基线训练好的权重。

保存独立 GenreOff 的逐轮训练记录到 `ablation_loss_curves.csv`。训练后逐种子比较它与 NeuralCF 的参数、预测、各项指标和训练曲线，差值写入 `ablation_checks.csv`。这项检查验证独立重训能否复现基线，不以加载同一权重后的相等代替。

`ablation.csv` 保留 Genre 开/关的全部评分、Top-K 和分组指标，`ablation_summary.csv` 按开/关及指标汇总均值、样本标准差和有效次数。图表重点展示 RMSE、MAE、NDCG@10。图中关闭项与 NeuralCF 的最大预测差指独立训练后的比较。类型模型的参数量可能更多，因此消融结果说明该实现中的增益，不能自动排除模型容量变化的作用；参数量匹配对照可作为额外研究。

## 8. 稀疏历史分组

分别计算训练中每个用户、每部电影的评分条数。仅对非零训练交互数量求低 25% 分位数，将交互数不超过阈值的用户/电影定义为对应稀疏组。

- 稀疏用户组：留出评分中，用户属于稀疏用户集合的记录。
- 稀疏电影组：留出评分中，电影属于稀疏电影集合的记录。
- 两组可以重叠；分别报告 RMSE、MAE 和样本量。
- 阈值和分组集合由训练数据定义并保存，不能用完整数据量分组；对应留出评分的样本量另行统计。
- 新用户/新电影的零历史情形另行记录，不混入相对稀疏组定义。

稀疏用户组的用户有训练历史，但对应电影仍可能是训练未见电影；稀疏电影组同理，可能对应训练未见用户。因此除原分组指标外，还记录另一侧为冷启动的评分条数，并另外计算两侧都在训练中出现的 warm-only 分组 RMSE、MAE及样本量。原分组用于描述整体表现，warm-only 结果帮助判断统一均值回退是否影响结论；二者不混用。

MovieLens 1M 原始用户至少有 20 条评分，因此该分组体现的是划分后相对较少的训练历史，不应将其称为严格的零交互冷启动实验。

## 9. 输出与复核

保留每个模型、每个种子的原始指标，以及数据来源、配置、划分统计、冷启动覆盖和训练日志。八类图表全部读取 CSV，不人工填写结果。

完成前检查正式配置至少有 5 个不同种子、五模型及独立 GenreOff 的执行记录齐全、所有要求指标均为有限数值；单种子 quick 仅用于调试。任何检查失败均报错，不写入 `complete` 状态。

误差条为跨种子的样本标准差，反映运行随机性；固定划分下的跨种子标准差不包含数据划分不确定性，也不等同于置信区间。训练曲线按每个 epoch 实际仍有记录的种子聚合；早停会使后段样本数变化。

最后讨论评分指标与排名指标是否一致、改进是否稳定、稀疏组是否获益，以及候选范围和冷启动回退对结论的限制。
